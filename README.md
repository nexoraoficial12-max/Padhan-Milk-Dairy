# Padhan Milk Dairy — Starter Frontend

Mobile-first Next.js frontend demo for Padhan Milk Dairy.

Included:
- Odia / Hindi / English language selection
- 3-second automatic Odia fallback
- Correct Odia UI wording
- Product cards, quantity controls and cart
- Customer name/mobile/address saved locally for this demo
- Monthly Plans & Offers placeholder section for future owner-controlled offers
- Supplied PhonePe QR
- Delivery information
- Contact and Google Maps link
- Responsive mobile layout

Important:
This is a frontend starter/demo. Real orders, customer accounts, live stock, owner/admin dashboard, subscriptions, billing, and payment verification still need a secure backend/database connection.
Do not treat the localStorage customer form as production authentication.

Product note:
Milk 250ml is currently shown as ₹15 based on ₹60/L; confirm this price with the client before launch.

Next phase:
Supabase + secure authentication + real database + live stock + order processing + owner dashboard + subscriptions + billing + payment verification.
